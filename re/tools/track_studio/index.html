2 · Identity
Read-only for now. Naming a track, switching it between circuit and point-to-point and setting its lane width are authoring controls, and authoring is parked — this studio currently loads and inspects shipped tracks rather than making new ones.
3 · Nodes
Read-only for now. Moving, inserting and deleting centerline nodes, and per-node lanes / width / surface, rewrite the track — parked with the rest of authoring.
4 · Branches
Read-only for now. Drawing a branch that peels off the main ring and rejoins it is authoring — parked.
5 · Checkpoints
Read-only for now. Checkpoint placement is authoring — parked. A loaded track still draws its own checkpoints; the gate toggle is in section 1.
6 · Environment
Read-only for now. Weather, traffic and fog are written into a track being built — parked. Loading a shipped track's own environment is in section 1.
