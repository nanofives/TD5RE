# x86_64 (64-bit) compile flags — the x64 retarget target (x64 Stage 3).
#
# Read IN ADDITION to cflags.txt, exactly like cflags_i686.txt. Deliberately
# short: nearly everything the 32-bit build needs is either arch-neutral (and
# so lives in cflags.txt) or redundant here.
#
# Why this exists at all: DXR requires a 64-bit process. Measured on an
# RTX 5070 Ti, RaytracingTier reads 0 in a 32-bit process and 12 in a 64-bit
# one, with WARP reporting 1.1 in BOTH as a control -- so the driver withholds
# DXR from x86, and no renderer change can work around it. See
# docs/plans/X64_DXR_ROADMAP.md.
#
# NOT here, and intentionally so:
#   -msse2 / -mfpmath=sse : mandated by the x86_64 ABI, redundant.
#   -DTD5_INFLATE_USE_ZLIB: the x86_64 toolchain ships no libz.a. td5_inflate.c
#                           falls back to its embedded tinfl decompressor, which
#                           is its documented default path, so nothing is lost.
-m64
